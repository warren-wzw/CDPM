Abstract

Cross-modal planar registration is challenging because geometrically corresponding regions may exhibit substantial appearance discrepancies. We present CDPM, a structure-aware dense matching framework that adapts pretrained DINO representations using geometric correspondence supervision, constructs a DINO-guided dual-path feature pyramid, and performs coarse-to-fine correspondence refinement.

Method Overview

1. Patch-level cross-modal DINO adaptation
